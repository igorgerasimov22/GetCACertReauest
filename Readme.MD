# Скрипт мониторинга ожидающих сертификатов CA


Автоматизированный скрипт для отслеживания запросов сертификатов в статусе **«Ожидает подтверждения» (Pending)** в центре сертификации **Windows (CA)** и отправки **email‑уведомлений**.

## Описание
Скрипт мониторит центр сертификации **(CA)** на наличие запросов сертификатов, ожидающих подтверждения, и отправляет **email‑уведомление** с таблицей таких запросов.

### Основные функции:
* получение списка запросов сертификатов в статусе **Pending**;
* извлечение ключевых данных: **ID запроса**, **запрашивающий**, **время запроса**, **шаблон сертификата**, **субъект**;
* формирование **HTML‑письма** с таблицей запросов;
* отправка **email‑уведомления** при наличии ожидающих запросов;
* обработка пустых значений полей (подстановка «Не указан»);
* поддержка кириллических символов (кодировка **UTF‑8**).

## Требования
### Программное обеспечение:
* Windows Server (с ролью AD Certificate Services);
* PowerShell 3.0 или выше;
* модуль PSPKI.
### Права доступа:
* учётная запись с правами на чтение запросов **CA**;
* доступ к SMTP‑серверу для отправки **email**.
### Установленные компоненты:
* роль **AD Certificate Services (AD CS)**;
* модуль **PowerShell PSPKI**.

## Установка и настройка
### Шаг 1. Установка модуля PSPKI
```powershell
Install-Module -Name PSPKI -Force
```
## Шаг 2. Настройка параметров скрипта
Отредактируйте следующие переменные в начале скрипта:

|Параметр|Описание|Пример|
|:-|:---|:--------|
|```$CAServer```|Имя сервера центра сертификации|```ServerCAName```|
|```$EmailFrom```|Email отправителя|```ca-monitor@domain.com```|
|```$EmailTo```|Email получателя(ей)|```recipient@domain.com```|
|```$SMTPServer```|Адрес SMTP‑сервера|```mail.domain.com```|
|```$SMTPPort```|Порт SMTP‑сервера|```25```|
|```$EmailSubject```|Тема email‑уведомления|```Оповещение: Новые сертификаты ожидают подтверждения в CA```|

## Шаг 3. Сохранение скрипта
Сохраните скрипт в кодировке **UTF‑8 с BOM**:
1. Откройте скрипт в PowerShell ISE или Блокноте.
2. Выберите **File → Save As**.
3. В выпадающем списке «Encoding» выберите **Unicode (UTF‑8 with signature)**.
4. Сохраните файл с расширением ```.ps1```.

## Использование
### Ручной запуск
```powershell
.\GetCACertReauest.ps1
```

## Автоматизация через Планировщик заданий
1. Откройте **Планировщик заданий** (Task Scheduler).
2. Создайте новое задание.
3. Настройте триггер (например, раз в 1 день).
4. В разделе «Действия» укажите:
    * **Программа**: ```powershell.exe```;
    * **Аргументы**: ```-ExecutionPolicy Bypass -File "C:\Path\To\GetCACertReauest.ps1"```;
    * **Запуск от имени**: учётной записи с правами администратора.

## Структура данных
Скрипт извлекает следующие данные из запросов CA:
|Поле|Описание|Источник данных|
|:-|:-|:-|
|ID запроса|Уникальный номер запроса|```$req.RequestID```|
|Запрашивающий|Учётная запись, запросившая сертификат|```$req.'Request.RequesterName'```|
|Время запроса|Дата и время подачи запроса|```$req.'Request.SubmittedWhen'```|
|Шаблон сертификата|Имя шаблона сертификата|```$req.CertificateTemplateOid.FriendlyName```|
|Субъект|Common Name (CN) сертификата|```$req.'Request.CommonName'```|

## Обработка особых случаев
* **Пустые поля**. Если поле пустое, скрипт подставляет «Не указан».
* **Отсутствие ожидающих запросов**. Скрипт завершается без отправки уведомления.
* **Ошибки**. При ошибках получения данных или отправки email скрипт завершается с кодом ошибки.

## Формат email‑уведомления
Письмо содержит:
* заголовок с указанием количества ожидающих запросов;
* HTML‑таблицу с данными по каждому запросу;
* подвал с подписью «Автоматическое уведомление от системы мониторинга CA».

## Устранение неполадок
### Распространённые проблемы и решения
|Проблема|Возможная причина|Решение|
|:-|:-|:-|
|«Кракозябры» в письме|Несовпадение кодировок|Убедитесь, что скрипт сохранён в UTF‑8 с BOM; проверьте поддержку UTF‑8 SMTP‑сервером|
|Пустые поля в таблице|Некорректные имена полей|Проверьте вывод ```Get-PendingRequest``` вручную; убедитесь в правильности имён полей|
|Скрипт не запускается|Отсутствие модуля PSPKI|Установите модуль: ```Install-Module -Name PSPKI -Force```|
|Ошибка доступа к CA|Недостаточные права|Запускайте от имени администратора или пользователя с правами на чтение CA|
|Не отправляется email|Проблемы с SMTP|Проверьте доступность SMTP‑сервера; убедитесь, что порт и настройки корректны|

## Команды для диагностики
```powershell
# Проверка доступности CA
certutil -ping

# Просмотр всех ожидающих запросов
Get-PendingRequest -CertificationAuthority "your-ca-server"

# Тестирование вывода с нужными полями
Get-PendingRequest -CertificationAuthority "your-ca-server" | Select-Object RequestID, 'Request.RequesterName', 'Request.SubmittedWhen', CertificateTemplateOid, 'Request.CommonName' | Format-List

# Проверка SMTP‑соединения
Test-NetConnection -ComputerName "mail.domain.com" -Port 25
```
